\# Linux Commands Reference



This document contains Linux commands I learn throughout this project.



\---



\# pwd



\## Command



```bash

pwd

```



\## Purpose



Displays the full path of the current working directory.



\## Example Output



```text

/c/Users/efrem/GithubProjects/ai-cloud-security-portfolio/projects/01-linux-security-lab

```



\## Why Security Engineers Use It



Security engineers frequently verify where they are before creating, deleting, or modifying files. Running commands in the wrong directory can cause mistakes or affect the wrong systems.



\---



\# ls



\## Command



```bash

ls

```



\## Purpose



Lists files and directories in the current location.



\## Example



```text

README.md

commands.md

notes.md

```



\## Why Security Engineers Use It



Used to inspect directories, verify files exist, and understand the structure of systems before making changes.



\---



\# cd



\## Command



```bash

cd <directory>

```



Example:



```bash

cd projects/01-linux-security-lab

```



\## Purpose



Changes the current working directory.



\## Why Security Engineers Use It



Used constantly when navigating servers, cloud instances, containers, and Linux systems.
