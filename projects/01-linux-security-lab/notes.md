\# Linux Filesystem Notes



\## Keywords Learned



\### Filesystem

The structure Linux uses to organize files and directories.



\---



\### Root Directory (/)

The highest directory in Linux. Every file and directory begins here.



\---



\### Directory

A folder in Linux.



\---



\### Path

The location of a file or directory.



Example:



/home/efrem/projects



\---



\### Absolute Path



Starts from the root directory.



Example:



/home/efrem/Documents



\---



\### Relative Path



Starts from the current working directory.



Example:



projects/



README.md



../



\---



\## Real World



Cloud servers, AI models, log files, configuration files, and automation scripts all exist somewhere inside the Linux filesystem.



Understanding the filesystem is the foundation of Linux administration and AI Security Engineering.
