\# Linux Security Lab



\## Overview



This project is part of my AI \& Cloud Security Engineering Portfolio.



The purpose of this lab is to build a strong Linux foundation for security engineering by learning the operating system that powers most cloud infrastructure and enterprise servers.



Rather than memorizing commands, this project focuses on understanding how Linux is used in real-world security engineering.



\---



\## Objectives



\- Learn essential Linux commands

\- Understand the Linux file system

\- Manage users and permissions

\- Secure files and directories

\- Practice Bash scripting

\- Build Linux skills required for cloud and AI security engineering
